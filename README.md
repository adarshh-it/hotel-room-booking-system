# 🏨 Hotel Room Booking System (C++)

## 📌 Description

This project is a **console-based Hotel Room Booking System** developed using C++.
It allows users to manage hotel room operations such as booking, checkout, searching rooms, and generating bills.
The system also uses **file handling** to store data permanently.

---

## 🚀 Features

* 🔐 User Login System (Username & Password)
* 📋 View Available Rooms
* 🛏️ Book Rooms
* 🚪 Checkout Rooms
* 🔍 Search Rooms by Type
* 🧾 Generate Bill
* 💾 Data Persistence using File Handling

---

## 🛠️ Technologies Used

* C++
* Object-Oriented Programming (OOP)
* File Handling (ifstream, ofstream)
* Console-based UI

---

## 📂 Project Files

* `main.cpp` → Main program source code
* `rooms.txt` → Stores room details and booking status
* `users.txt` → Stores login credentials
* `bill.txt` → Generated bill file (auto-created)
